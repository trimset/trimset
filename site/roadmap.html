Roadmap

Where trimset is

One maintainer, in the open, one milestone at a time. Every milestone ships something you can run. Dates are set after each one, from how long the last really took.

  1. M1

    Capture

    Logging through the proxy or the API, late outcomes joined to their decisions, default labels by rule.

    In progress
  2. M2

    Calibrate and compile

    Calibration per question and model, the policy compiler with stated guarantees, and the trimset CLI.

    In progress
  3. M3

    Gate

    The Python SDK’s gate(), policy approval with an audit trail, and one-command rollback.

    Planned
  4. Alpha

    First release

    M1 to M3 released: the container image, the Python package, a quickstart and the self-hosting guide.

    Planned
  5. M4

    Watch

    Drift checks with significance tests, silent-upgrade detection and alerts.

    Planned
  6. M5

    Compare and review

    Shadow models on live traffic, a review queue for escalated decisions, and data retention and deletion.

    Planned
  7. v0.1

    Launch

    The first stable release: everything above, documented, with runnable demos for refund fraud, ticket triage and model routing.

    Planned
  8. v0.2

    Dashboard and TypeScript

    A web dashboard and a TypeScript SDK.

    Later

Follow along, or pick up an issue, on GitHub.
