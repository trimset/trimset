Keep your decision thresholds true.

trimset is decision ops for decision models like Jev, Ollaya and Ollama. It logs every decision, joins it to what really happened, refits your thresholds and tells you when the model drifts.

Thresholds you set once go stale.

Everyone writes if p > 0.9 and never checks it again. trimset closes the loop in four steps.

01 · Capture

Log every decision

Through the proxy or the logging API. Probabilities, model version, latency and cost. Raw state is never stored.

02 · Join

Match real outcomes

Chargebacks, reviewer labels, reassignments. Outcomes arrive hours or months later and attach to the original decision.

03 · Refit

Compile a policy

State a target like "at most 2% false passes". trimset recalibrates and proposes thresholds and an escalation band.

04 · Enforce Coming soon

Ship it to your apps

You approve, the SDK picks it up and gates locally, with no network call on the request path. Roll back with one command.

Built for System One models

Pre-alpha. The roadmap says what works today and what is coming.

Calibration per question

Temperature, Platt and isotonic fits per question wording and model. Never pooled across them.

Escalation bands

Confident cases run on System One. The uncertain middle goes to an LLM or a human.

Drift alerts that mean it Coming soon

Label-free distribution drift with significance tests, so small samples don't page you at 3 a.m.

Silent upgrade alerts Coming soon

Know the moment an alias like jev-latest starts answering with a new version. trimset already records which version answered.

Shadow models Coming soon

Run an open model next to your hosted one on live traffic and compare before you switch.

Review queue Coming soon

Escalated cases land in a queue. Every reviewer label becomes training signal for the next refit.
